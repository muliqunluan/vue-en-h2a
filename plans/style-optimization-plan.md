## 任务 2：Apple 翻译 App 风格重设计 — [WordInput.vue](src/views/WordInput.vue)

### 设计参考：Apple 翻译 App

Apple iOS/macOS 翻译 App 的核心设计特征：
- 上下双面板布局（源语言 / 目标语言）
- 源语言输入区：底部有输入框 + 键盘
- 目标语言输出区：大号文字展示翻译结果
- 语言选择器在顶部，中间有交换按钮
- 极简的白色/浅灰背景
- SF Pro 字体家族（系统默认字体）
- 大号圆角卡片容器
- 精妙的分隔线和阴影
- 平滑的过渡动画

### 映射关系

| 翻译 App 元素 | 本项目对应 |
|--------------|-----------|
| 源语言（如 English） | 用户输入的英文单词 |
| 目标语言（如 Chinese） | 用户猜测的含义 |
| 翻译结果 | AI 验证后显示的真实含义 |
| 语言交换按钮 | 步骤回退（回到单词输入） |
| 收藏按钮 | 匹配度状态指示器 |
| 输入框 | 单词/猜测输入 |
| 翻译历史 | 已记录单词列表 |

### 页面结构重设计

#### 步骤 0：输入英文单词

### 关键 CSS 设计 Token

```css
/* Apple 翻译 App 设计 Token */
--color-bg: #ffffff;           /* 主背景 */
--color-bg-secondary: #f2f2f7; /* 次级背景（卡片/输入框） */
--color-text-primary: #1c1c1e; /* 主要文字 */
--color-text-secondary: #8e8e93; /* 次要文字 */
--color-accent-blue: #007aff;  /* 强调蓝 */
--color-accent-green: #34c759; /* 匹配成功 */
--color-accent-red: #ff3b30;   /* 匹配失败 */
--color-border: #e5e5ea;       /* 分隔线 */
--color-language-tag: #e5e5ea; /* 语言标签背景 */
--radius-card: 14px;           /* 卡片圆角 */
--radius-input: 12px;          /* 输入框圆角 */
--shadow-card: 0 2px 20px rgba(0,0,0,0.06); /* 卡片阴影 */
--font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'SF Pro Text', system-ui;
```

### Apple 翻译 App 特有的交互细节

1. **语言标签（Pill 形状）**:
   ```
   [EN 英语]           [CN 中文]
   ```
   使用 pill 形状带背景色，中间用箭头连接

2. **输入框聚焦效果**:
   - 聚焦时显示蓝色边框 + 轻微阴影
   - 输入框左侧有一个小的语言指示图标

3. **结果页动画**:
   - 单词显示时：从底部滑入 + 淡入 (translateY + opacity)
   - 匹配度标签：缩放入场 (scale)
   - 源语言→猜测→真实含义 按顺序入场（staggered animation）

4. **"继续"按钮**:
   - 使用系统蓝色 `#007aff`
   - 圆角胶囊形状
   - 文字白色

## 任务 3：统一全局样式优化

### [`App.vue`](src/App.vue) 全局样式修改

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'SF Pro Text',
    'Helvetica Neue', sans-serif;
  background: #ffffff; /* 从 #f5f7fa 改为白色 */
  color: #1c1c1e;     /* 从 #333 加深 */
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

- 服务器状态栏：简化为纯文字，去掉 emoji，使用纯 CSS 颜色指示
- API Key 配置区域：使用更简洁的卡片样式，与翻译 App 风格统一
- 按钮统一使用胶囊形状 (border-radius: 999px)

### 组件级样式统一

#### 步骤指示器
- 从当前 `background: #4a90d9` 改为 Apple 风格
- 使用更柔和的灰色背景 + 蓝色强调
- 移动端改为水平滚动而不是垂直堆叠

#### 输入框
- 统一为 Apple 风格的圆角输入框
- 聚焦时蓝色边框 + 阴影
- placeholder 使用 `#8e8e93` 灰色

## 任务 4：移动端适配

保留并增强现有的响应式设计：
- `< 480px`：小屏手机优化
- `481px - 600px`：中屏手机

- 卡片内边距缩小但保持视觉一致性
- 语言标签适当缩小字号
